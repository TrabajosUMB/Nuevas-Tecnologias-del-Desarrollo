Sobre el Proyecto Sobre el Proyecto

TechCompareApp es una aplicación híbrida desarrollada con Ionic y Angular como proyecto de semestre para el curso de Nuevas Tecnologías del Desarrollo. Su objetivo es comparar y clasificar aplicaciones móviles según su tipo (nativa, híbrida o web/PWA), tomando como casos de estudio Nubank y Steam. La app permite explorar las características, ventajas y limitaciones de cada tipo de app, y sirve como demostración práctica del desarrollo multiplataforma con Ionic/Capacitor.
