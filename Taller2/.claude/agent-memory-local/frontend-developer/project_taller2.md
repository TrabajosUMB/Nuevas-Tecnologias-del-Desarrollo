This is a university workshop project (Taller2) focused on Flutter/Dart development targeting Android and Windows desktop platforms. Sessions are organized under Sesion1, Sesion2, etc. subfolders within the Taller2 directory.

Session progression (contador_app):
- Session 1 (baseline): basic StatefulWidget counter with a single increment FloatingActionButton.
- Session 2 (2026-09-02): added reset FAB (Icons.refresh, redAccent color, heroTag required) and dynamic Scaffold backgroundColor (Colors.lightGreen[100] when counter % 5 == 0 && counter > 0, else white). Also added AnimatedOpacity indicator for multiples of 5. App version bumped to 2.0.0+1.

Deliverables per session: lib/main.dart, pubspec.yaml, README.md, informe/informe_sesion{N}.md (APA 7 academic report template in Spanish).

## EcoLogix Case Study (2026-09-02)

A full Flutter + Firebase app built as a university case study deliverable. Located at `EcoLogix/ecologix/`. Structure:
- `lib/main.dart` — Firebase.initializeApp, MaterialApp with green theme, useMaterial3: true
- `lib/firebase_options.dart` — Placeholder with student instructions; real file generated by `flutterfire configure`
- `lib/models/recoleccion.dart` — Immutable model with toMap/fromMap/fromFirestore, tiposMaterial const list
- `lib/services/firebase_service.dart` — FirebaseService with getRecolecciones() Stream and agregarRecoleccion() with two-layer validation, custom RecoleccionInvalidaException
- `lib/screens/home_screen.dart` — StatelessWidget with logo, title, two navigation buttons
- `lib/screens/registro_screen.dart` — StatefulWidget form with Dropdown, numeric TextFormField, DatePicker, loading indicator
- `lib/screens/lista_screen.dart` — StreamBuilder with empty/error/data states and total-kg banner
- `informe/pitch_seguridad.md` — Security analysis: centralized DB vs Blockchain
- `informe/informe_caso_estudio.md` — Full APA academic report

**Why:** Course requirement for "Nuevas Tecnologias del Desarrollo" at the university (2026-02 semester).

**How to apply:** When creating Flutter projects for this workshop, place them under `Sesion{N}/` subdirectories (or named sub-folders like EcoLogix/ for case studies), use Spanish for UI text and comments, ensure pubspec.yaml targets sdk: '>=3.0.0 <4.0.0' with useMaterial3: true, and always check previous session's main.dart before writing new code to maintain continuity. Academic reports use APA 7 format in Spanish, placed in an `informe/` folder inside the project.
