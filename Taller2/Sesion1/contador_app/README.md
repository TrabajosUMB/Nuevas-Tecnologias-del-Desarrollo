# Contador App

Aplicacion de contador simple desarrollada en Flutter/Dart.
Proyecto de la Sesion 1 del taller universitario de Nuevas Tecnologias del Desarrollo.

## Requisitos

- Flutter SDK >= 3.0.0
- Para Windows desktop: Visual Studio con el workload "Desktop development with C++"

## Instrucciones para correr

### Verificar instalacion de Flutter

```
flutter doctor
```

### Android (emulador o dispositivo fisico)

```
flutter run
```

> Asegurate de tener un emulador Android corriendo o un dispositivo conectado con depuracion USB habilitada.

### Windows Desktop

```
flutter run -d windows
```

> Requiere Visual Studio 2019 o superior con el workload de C++ instalado.
